# Project Overview

This project is a personal link-in-bio web application built with Python and Flask. Users can add URLs, and the application displays them as styled link cards with a preview of each page that can be viewed by clicking the preview.

## Tech Stack

- Python
- Flask
- HTML

## File Structure

The project should use the following structure:

- `app.py` — main Flask application and application logic.
- `templates/` — HTML templates used to render the web interface.
- `static/` — static assets such as CSS files.

Keep the project structure simple and avoid introducing unnecessary files or dependencies.

## Coding Conventions

- Use clear and descriptive variable and function names.
- Add comments only where the logic is not obvious.
- Keep functions small and focused on a single responsibility.
- Prefer simple, readable solutions over unnecessary complexity.
- Follow standard Python conventions.

## Testing

After making changes:

1. Run the application with:

   `python app.py`

2. Confirm that the Flask development server starts without errors.
3. Verify that the changed functionality works as expected.
4. Fix any errors before considering the task complete.
